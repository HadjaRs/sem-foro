# 🚦 Semáforo Inteligente com Arduino

Projeto desenvolvido para praticar programação embarcada utilizando **Arduino Uno**, **C++** e **PlatformIO**.

## 📋 Descrição

O projeto simula o funcionamento de um semáforo com três LEDs.

O sistema funciona automaticamente e também possui um botão para pedestres. Quando o botão é pressionado durante o sinal verde, o sistema interrompe o tempo restante do verde e inicia a sequência de amarelo e vermelho.

---

## ⚙️ Componentes

- Arduino Uno
- Protoboard
- 3 LEDs
- 3 Resistores de 220 Ω
- Push Button
- Jumpers
